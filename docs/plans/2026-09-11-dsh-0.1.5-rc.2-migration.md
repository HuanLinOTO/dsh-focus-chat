## 本插件触点分析

- **RC2-01 / RC2-02 · 非命中**：插件的 feedback 控制器与操作条是**自制 vendored 实现**
  （`src/client/model/feedback-controller.ts`、`src/client/view/chrome/MessageFeedbackActions.tsx`），
  未 import `@deepseek-ai/dsh-client-ui-message-feedback/client` 的注入契约（仅 `@module` 注释引用模块名，
  无 `MessageFeedbackInjected` / `FeedbackDialogInjected` / `MessageFeedbackToggleResult` 引用）。
  rc.2 不变式覆盖：座位名/顺序/props 接口名不变。插件自有 UX（点击立即记录 + note 弹层）是**有意分叉**：
  它接管的是 assistant-actions 条的业务面，驱动的是 Host 侧 messageFeedback remote（RC2-06 证明 Host 面零变更），
  上游 rc.2 的弹窗确认流发生在其自身组件内部，不会传导到本插件的接管面。
- **RC2-03 · 非命中**：src 无 `FileTypeIcon` / `CodeFileIcon` / `dsh-code-icon-*` / 快照断言。
- **RC2-04 · optional，选择不改**：`TurnTailRow` 是插件自有的回合尾流（`.turnTail { gap: 16px }` +
  `.producedRow { margin-top: 16px }`，自成一体）。上游 20/16/20px 契约描述的是 ui-chat / ui-deliverables
  内建渲染器之间的流间距；本插件整体接管聊天流，该契约不约束自有流。若后续想与上游视觉契约对齐
  （produced 行 margin-top 16→4px），另开独立任务，不属本走廊必需项。
- **RC2-05 · 非命中**：不渲染 feedback 分类文案。
- **RC2-06 · informational**：本插件 peer 的 `@deepseek-ai/*` 包无改名/移除。
